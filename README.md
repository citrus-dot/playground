# playground

成就刷取场（GitHub Achievements playground）。

本项目专门用于在自己的公开仓库合法完成 GitHub 成就（Pull Shark / YOLO / Quickdraw / Pair Extraordinaire）。
所有 PR 与 issue 均为成就触发操作，不代表真实开发内容。

| 成就 | 触发动作 | 状态 |
|---|---|---|
| Pull Shark | merged PR ×16（铜级） | 进行中 |
| YOLO | merge 无 review 的 PR | 进行中 |
| Quickdraw | 开 issue 后 5 分钟内关闭 | 进行中 |
| Pair Extraordinaire | co-authored commit 进入 merged PR | 进行中 |
